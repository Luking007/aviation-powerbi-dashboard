## Project Overview
Full interactive Power BI dashboard analyzing Nigerian domestic
airline operations across 5 carriers and 6 routes — Jan–Jun 2025.

Built using a Star Schema (4 connected tables):
- Flights (Fact Table) — 6,291 rows
- Airlines (Dimension) — 5 airlines
- Routes (Dimension) — 6 routes
- Date Table (Dimension) — 181 days

---

## Key Findings

| Metric | Value |
|--------|-------|
| Total Flights | 6,291 |
| Total Revenue | ₦125.5bn |
| Total Profit | ₦25.6bn |
| OTP Rate | 28.8% |
| Avg Load Factor | 75.5% |
| Cancellation Rate | 0.64% |

- No Nigerian domestic airline hit the 70% OTP benchmark
- Air Peace leads OTP at 31.4% — still below industry standard
- Every route operates above 65% break-even load factor
- LOS–KAN is highest load factor route at 76.3%
- All 5 airlines profitable — United Nigeria leads at ₦5.5bn
